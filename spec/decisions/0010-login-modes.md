# 0010 — Login modes: password, password + TOTP

- **Date**: 2026-11-10
- **Decided by**: author
- **Status**: amended by 0021: two-password mode supported (FIDO2 still refused)

v1 supports password-only and password + TOTP accounts. Two-password mode comes later; FIDO2 is refused. The test account has TOTP on and two-password off, is empty, and may be filled with any synthetic data, years back included.
